# DaLentini — Menu & Brand Generator

Generatore **offline** di menù e brand guidelines per l'home restaurant **DaLentini**.

## Contenuto
- `index.html` — entry point
- `Menu Generator.html` / `DaLentini Menu Generator (offline).html` — generatore menù
- `Brand Guidelines.html` / `DaLentini Brand Guidelines (offline).html` — linee guida brand
- `menu-data.js`, `menu-generator.css`, `menu-form.jsx`, `menu-sheets.jsx` — sorgenti

App single-file: funziona offline direttamente nel browser.
